Express JS working life cycle
user enter on our website send request to expressJS. Express checks, is it valid request or not. If yes, so response other wise not

2. app.listen(3000, ()=>{		-> es way sy hm apny project ko local-port pr run krty hn

   })					-> agr hm listen nh lgaengy to express js hmari kisi request ko handel nh kryga

// if want to send parameter in route (Example of route parameter)
http://localhost:3000/user/10			-> this is route
app.get('user/:userid', (req, res)=>{ res.send( req.params) }) -> this is route handler in expressJS

// for multiple parameter
http://localhost:3000/user/10-22	-> i seperated with - 
app.get('user/:userid-:bookid', (req, res)=>{ res.send( req.params) })
it will return {  userid: "10", bookid: "22" }  


// Example of Query parameter

http://localhost:3000/search?id=13
app.get('/search', (req,res)=>{ res.send(req.query) })   -> show query parameter values
it will return  { id: "12" }



// for multiple 

http://localhost:3000/search?id=13&city=karachi
app.get('/search', (req,res)=>{ res.send(req.query) })   -> show query parameter values
it will return  { id: "12", city: "karachi" }
