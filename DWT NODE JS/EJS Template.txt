it is template engine

TAGS
<% %>	-> Control flow, no output. 
	<ul>
	<% for(let i = 1;i<=3; i++){%>
            <li>Item <% i %></li>
	<% } %>
<%= %>	-> Outputs escaped value (safe)
<%- %>	-> Outputs unescaped value (unsafe)
<%# %>	-> Comment (not shown in output)
<% -%> 	-> Removes the following newline. aksar new line automatic ajati ha essy nh aygi
<%_ %>	-> Removes whitespace before it 
<% _%>	-> Removes all whitspace after it

-- Loop
<ul>
 <% let items = ["APPLE", "ALI", "PAER"] %>   <!-- set variable -->
 <% items.foreach(item => { %> 		<!-- start loop -->
	<li> <%= item _%> </li>  	<!-- show values -->
 <% }) %>
</ul>
