Type of Middleware
. Application-Level Middleware		// use for all routes in whole application
. Router-Level Middleware	// we use middleware with router in express. can use in specific route
. Error-handling Middleware	// if any route has error so we can handle error with it
. Built-in Middleware		// bulit in middleware which are already in express 
. Third-Party Middleware	// there are some packages which gives us some middleware that we can use

================== Router-Level Middleware

1. const express = require("express")
2. const app = express();
3. const router = express.Router();

router.use((req, res, next)=>{
 console.log("Hello Bilal")
 next()
})

router.get('/about', mymiddleware , (req,res)=>{  })

app.use('/', router);  // this will run my router and middleware as well otherwise router will not run as well
